# SCHEDULE-TRACKER-PROJECT
My 1st quarter project in comsci

INTRODUCTION:
Schedule Tracker is a simple program designed to help users manage their daily routines and keep track of their personal tasks. It allows users to create schedule entries with specific start times, end times, and categories, while preventing overlapping appointments through built-in time conflict detection.

HOW IT WORKS:
The program runs through a simple main menu where users can choose to add new events, view their current timetable for the day, or exit. When adding a new entry, the system checks existing tasks to ensure no two events conflict with each other, keeping your day organized and stress-free.
